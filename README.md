# 星穹铁道 · 2222

一部约 **4 分 14 秒**的电影式科幻项目路演：从人类走出地球的必然推演，到行星环轨、动能回收、地火货运与群星建港，再讲述商业与投资。

首页包含 18 幕自动播放场景，支持暂停、跳幕、倍速和手机滑动。点击“开启配乐，从头播放”后，音乐与影片同步；原理演示和收益模型可从目录打开。图片、音乐、脚本均随站点提供，播放无需访问第三方资源。

## 发布与预览

这是无需构建的静态网站。将仓库的 GitHub Pages 发布源设置为 `main` 分支根目录即可；`.nojekyll` 会保留原始静态文件。

目标地址：<https://cheng-xiu.github.io/astral-rail-2222/>。该地址在仓库发布配置生效后可用。

本地预览：在此目录运行 `python -m http.server 8000`，然后打开 <http://localhost:8000/>。请通过本地 HTTP 服务预览，页面使用 ES 模块。

入口：`index.html`（电影路演）、`principle.html`（原理拆解）、`explore.html`（项目与收益模型）。路径均为相对路径，可部署到项目子目录。
